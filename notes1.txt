  package-lock.json -> 

  major version upgrade can break your existing applicaions.

  express: ^ 4.19.2 -> auto update to 4.x.x

  express: 4.19.2 -> will always use this version, will never auto update

  express: ~ 4.19.2 

  major version update will not auto update, only patch updates and minor version updates auto upgrade happens.

  package.json contains (express: ^4.19.2) -> does not show the exact version. Tells the nomenclature, what versioning system it should use.

  applicaion always uses the latest version.

  package.lock.json -> tells you the exact version.
